An academic project (2024 - 2025) on making intrusion detection less manual.

* Automated key parts of the intrusion detection workflow, reducing manual analysis effort and improving detection speed by approximately 40%.
* Assisted in analyzing network traffic to identify suspicious activities.
* Supported the development and testing of a Flask-based validation interface.

**Stack:** Python, Flask, network traffic analysis
